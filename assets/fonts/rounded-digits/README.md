# Rounded digit font

Baloo Bhaijaan 2, weights 400–800, supplied by Google Fonts under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt). The local WOFF2 contains Western, Arabic-Indic and Eastern Arabic-Indic digits. The CSS face is restricted to those digit ranges so Arabic text and mathematical symbols retain their existing fonts.

Source family: https://github.com/google/fonts/tree/main/ofl/baloobhaijaan2

Digit subset: https://fonts.gstatic.com/l/font?kit=zYX9KUwuEqdVGqM8tPDdAA_Y-_bMMIN-Q-faPFhJxApuMbohpVfApXZagcP32S3kOF4JMkgGvI4tNR_VCrBKIc03TlRAyvvMDBbA&skey=4d6e60756ab902b1&v=v21

`src/styles/base.css` owns the numeric face and UI font roles; `src/styles/lesson/math.css` applies it within native MathML.
